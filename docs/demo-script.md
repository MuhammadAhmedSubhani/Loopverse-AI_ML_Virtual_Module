# Live demo script (target 3–5 minutes)

Use a real run on the machine you will present from. Do not present generated fixtures as a live model run.

1. **0:00–0:30 — Mission control.** Start the server, open the dashboard, point out the five agents, resource pool, validation panel, and provider status.
2. **0:30–1:30 — Baseline negotiation.** Start a baseline scenario. Show agent proposals, counteroffers, any refusal, two return commitments if a sacrifice is selected, validator checks, plan version, and four votes.
3. **1:30–2:15 — Verify the AI source.** If using a provider, open LLM settings, run Test, and show `source: llm` on real agent messages. If the provider fails, disclose rule-fallback; do not call that a live AI run.
4. **2:15–3:15 — Inject an emergency.** Submit the official Solar Aftershock event through the API or use the dashboard's resource-delta control. Show the prior plan marked stale and the council negotiating a new version with fresh votes.
5. **3:15–4:00 — Validation and exports.** Show PASS/FAIL reasons, current plan, persistent transcript, and download JSON/CSV. Briefly show `starter_kit_records` in the JSON export.
6. **4:00–4:30 — Close.** Explain that deterministic rules, not the LLM, enforce resource/risk/commitment/vote gates.

Before recording: reset the scenario, verify the provider connection if claiming live AI, and ensure no API key is visible on screen.
